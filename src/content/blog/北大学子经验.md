## 学院介绍
北京大学的工科教育历史悠久，1910 年 3 月即组织了工学院（当时称工科分科大学）
工学院从成立开始就从高起点出发，立足于尖端科技、交叉学科，着眼于未来工程科学和新技术的发展方向，面向国家迫切需要及关系国家中长远经济发展的科学与技术研发。因此，北大工学院的发展以培育核心创造能力为中心，有所为、有所不为，优中求精。同时，学院采用与国际接轨的院长负责制，实行“教授治学，民主治院”。学院重建以来，在学科发展、队伍建设、科学研究、人才培养、合作与发展等方面取得了突出成绩。学院现设有 5 个系，以及湍流与复杂系统国家重点实验室、北京市工程科学与新兴技术高精尖创新中心等多个重要研究机构，它们中不少已经进入世界先进学科的行列。

## 数学

1. 大量刷题是必要的
   >首先{% label 刷大量的题 orange %}。新知识学习阶段是在老师的指导下进行系统的学习并完成的相应练习，记为“课内题”，得以巩固。如果能在老师的布置之外自己再完成对应课程的其他题，记为“课外题”，这样基础会更扎实。
2. 要有效率地订正答案
   >{% label 自己对答案的时候尤其需要认真 orange %}。不能只看答案正确与否，需要{% label 将自己的思路和答案的思路比对 orange %}。若相同，则学习记忆参考答案的步骤，确保自己下次做类似题不会因步骤不全而扣分；若不同，首先理解参考答案的思路，在闭卷的情况下能完整地运用参考答案的思路解题。同时，{% label 保证步骤细节完善 orange %}，然后核查自己的思路有无问题，如果不能确定，就去咨询老师或同学，{% label 再比较两种思路，比如哪种更通俗、更快捷、更安全（不易算错、不易写错、不易被扣分），更符合个人的思维习惯等。 orange %}接下来{% label 进行取舍，选择最佳思路 orange %}，在下次解类似题时{% label 偏向该思路 orange %}，但也要{% label 熟悉另外多种思路方式，避免最佳思路行不通时无路可走 orange %}。

3. 要经常回顾题目并对题目分类
   >就我而言，做过的题可以分为简单题（掌握知识点就能做对）、易错题、难题（花费很长时间，在知识的基础上需要大量的思考和尝试，计算能力要足够高，还需要一定的技巧）、巧题（有特定、快捷的解题模式）、模糊题（在限定时间内模糊一些步骤，连蒙带猜得出正解）。

   >刷题后间隔一定时间（3～8天，根据自己的记忆习惯来定）进行再刷。再刷的时候就要看自己对以做题的分类了：    
   >{% label 简单题 blue %}：没必要再刷，如果简单题出错就要翻看教材，最好对相关知识安排一次早读；    
   >{% label 易错题 blue %}：{% label 间隔较长周期多次刷，并且总结错误类型和将再刷的正误记录 orange %}，若连续正确三次就可以将该题从刷题列表上划去了；    
   >{% label 难题 blue %}：{% label 我建议每天一道来进行训练 orange %}，自己评分找快感。{% label 当天题当天解决弄懂 orange %}，能默写出正解，{% label 对于前次未做出来的题隔天再做一次 orange %}。当然隔天有隔天的任务，旧题不能代替；    
   >{% label 巧题 blue %}：需要记思维记题型，学会举一反三，但我认为尤其重要的是记住条件，特别思维方式的适用条件，否则容易一味找捷径，花费的时间比常规方法还长，最后还发现脑海中的巧解并不适合该题；    
   >{% label 模糊题 blue %}：在对答案后要注意自己模糊之处的正确书写以及得分点，以免模糊过多形成习惯导致解题断片、答案扣分等。    

   >对做过的题{% label 进行熟悉总结和分类，形成自己的一个题库。 orange %}不一定要装定裁剪成册，只需要{% label 碰到某种类型的题时，自己知道能在哪里找到曾做过的，知道曾做过的题是怎样做的，共有多少方法可以解决 orange %}就可以。

4. 要善于把握考试时间
   >{% label 考前对自己催眠，将考试时间缩短半个小时 orange %}。关于考试，我尝试过这种方法，对于题做不完的同学来说可能有较大用处。比如说规定时间是14:30～16:30，就暗示自己16:00就要交卷了。{% label 能有效加快自己的做题速度，增强紧张感。 orange %}毕竟有种说法叫“急中生智”，这种情况下思维能更灵活。我曾有过好多次这样的经历，倒不是自我催眠，只是记错了交卷时间。这样考试获得的结果都还不错，对于我从习惯性做不完试题到完成试卷有很大的激励意义。

   我也是那种做不完题目的人🤣🤣🤣，这种方法对我很有帮助

## 语文

1. 要增强读书的{% label 广度 blue %}与{% label 速度 blue %}
   >{% label 学会自己延长早读时间 orange %}，包括单纯的时间和{% label 读书速度及效度 orange %}。{% label 读的内容要跨度广 orange %}，比如诗歌及诗歌赏析、时事素材、文言文词句释义、范文及优美段落、范例题和错题、语法和知识点等。   
2. 看书时多摘抄文段，勤背诵
   >另外{% label 阅读有趣且有益的书籍 orange %}，主要根据个人喜好决定。偏文学方面的可以读散文集，比如史铁生的《扶轮问路》《病隙碎笔》《放下与执着》《我与地坛》等，简媜的《水问》《唯有相爱，可抵岁月漫长》等，李娟的《冬牧场》《遥远的向日葵地》等，梁静的《看见》等大家作品或获奖作品。  
   >{% label 常看常摘抄对于文笔的修炼有好处 orange %}，另外文章中的哲思，若是{% label 有一定理解了运用在作文中也相当有思想深度。 orange %}偏理科方面的可以读牛顿的《自然哲学的数学原理》《费恩曼物理学讲义》《上帝掷骰子了吗》《science》杂志等，可以自己试着去找。这些书对概念的理解对开阔解题思路有益，也能给扎堆题海的我们一点轻松愉悦的体验。
   >记得多。费尽心思才行。晨起睁眼背诵一段文章，去食堂的路上念念必背的诗歌，出操的时候拿一张文化常识单子，回宿舍的时候再背背文言文，晚饭时间可以记记范例题及答案。努力做到语法知识点信手拈来，各主题的出色论点绝佳段落张口即出。(~~内卷？~~)

3. 多练习，熟悉题型
   >{% label 练得多 orange %}。练要{% label 循序渐进、笔耕不辍、积少成多 orange %}。{% label 各类型（主要是高考题型）的题要“雨露均沾”，可以适当偏爱那些灼手挠心的题。 orange %}还有{% label 练笔，要经常输出才行 orange %}，我之前的计划是两天写一小段，每周整理。虽然没有最终坚持下去，但是练笔之后那段时间，写作文相当流畅，效果是很好的。另外{% label 还要有自己拿得出手的文章 orange %}。可以就从平时老师布置的作文题或者测试中的作文题，选择自己拿手的、有想法的或者难为的、一窍不通的来写。{% label 和老师讨论，看看自己作文的优缺点并作修改，改了再去问问老师，继续修改 orange %}，直到蜕变成满分作文。
   >打造一篇作文的时间往往不短，要有思维断片的预设准备，若卡壳了就再等等，有想法有思路之后再继续写，大概重要的是耐心和决心。
   >{% label 见得多 orange %}。这个主要是{% label 拓宽眼界 orange %}。包括新题型：{% label 阅读设题方式及对应解答思路，相应的文言文、诗歌赏析、默写、语言文字运用，作文写法和各色主题等 orange %}。见得多可以让你在{% label 面对新题时不慌张，形成清晰的答题思路。 orange %}
4. 多思考，找到适合自己的审题作答模式
   >{% label 思得多。 orange %}记背的东西多了，就容易漏掉思考；套路模式见多了，也容易忽略思考。要知道所谓的答题格式都是人总结琢磨出来的，而{% label 考生应该从格式的拘束中跳脱出来，活学活用 orange %}。{% label 想清楚答案为什么是答案，你怎样做出你的答案，为什么没有体会到出题意图，为什么没有感同身受等。 orange %}作文也是，当拿到一个主题，应该{% label 先充分思考，挖掘自己的想法 orange %}，而不能首先是翻阅脑袋里的库存，找类似的范文。思考多了，文字会更深刻，你就可以写出一篇新颖别致的好文。

## 英语

<p align="center">众所周知，英语很</p>
<h1 align="center"><font size='60px' color="#ffffff">白</font></h1>
<p align="center">因此学长给出的方法不多</p>

1. 听力要专注，可以开倍速
   >在最后复习那段时间，我会隔日去办公室借老师的电脑练习听力，用午休的部分时间做一套听力题。{% label 在练的时候，我一般用1.25和1.5的倍速。 orange %}听力还需要{% label 练习严谨的态度，不论简单还是难，都不走神。 orange %}以免听正常语速的听力时由于轻视走神而导致出错丢分。我在听下次听力时，会{% label 把上次没听懂的、做错了的题再听一遍。 orange %}
2. 要按照模块总结知识点
   >首先{% label 语法要记熟 orange %}，然后练题检测，反复测，{% label 把每道题的知识点考点弄清楚 orange %}，查漏补缺。哪块薄弱就重点关照，{% label 做过的错题也得多看 orange %}。早读的时候多背背语法，晚自习要挤时间出来复习看过的内容。
   >对于{% label 应用作文，逐个分类 orange %}。比如{% label 演讲稿、倡议书、介绍信、建议信、报告类、日记等 orange %}。往往每个类别有内容元素的不同要求，可以准备一些语段、词句。对于叙写，{% label 高级词汇，修辞，主旨句之类的都要随时备着 orange %}。
3. 续写需要多练习
   >英语作文也需要多练习，包括两种训练，{% label 一是练习思路把握主旨，二是练习速写书写和文笔。 orange %}前者，可以只看题，{% label 谋划谋划情节线，再比对答案； orange %}也可以{% label 写出大略提纲，关键句，想到的高分词汇等。 orange %}重点在多练，阅尽叙写，情节自现。后者，{% label 要善于寻找发现美句，并善于记录； orange %}四级词汇最好每天都不要落下；维克多也很好。
