这是一份面向零基础学习者的 Python 入门书，依据 ARES 算法组《P001.Python入门》课件整理。书中保留了课件中的全部代码示例，并把分散在 58 页幻灯片中的内容重新组织成可以连续阅读、复制与运行的章节。

> **如何使用本书**
>
> 遇到代码单元时，先预测运行结果，再执行验证。含 `input()` 的单元需要你在运行时输入数据；安装命令应在终端而不是 Python 单元中执行。

## 学习路线

1. 输出、变量与报错
2. 字符串、数值与布尔值
3. 字符串和列表操作
4. 顺序、分支与循环
5. 函数与变量作用域
6. 类、对象与继承
7. 模块、第三方库与虚拟环境
8. 猜数游戏与计算器类

## 整理说明

- 代码拼写、大小写和缩进均按课件逐页核对。
- 重复出现的同一代码只保留一次；逐步补全的代码保留各阶段版本。
- 课件为了教学而故意留下的错误会放入非执行代码块，并解释错误原因。
- `range()` 在 Python 3 中返回可迭代的 `range` 对象，不直接返回列表；本书在不改变原例用法的前提下补充了这一点。
- Python 官方风格推荐每级缩进 4 个空格，避免混用 Tab 与空格。
